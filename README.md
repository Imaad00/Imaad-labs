# Personal Portfolio

A responsive personal portfolio showcasing my software development projects, technical skills, education, professional experience, and achievements.

I enjoy building practical applications using Python, backend frameworks, and AI/ML technologies.

## Features

- Responsive portfolio layout
- Light and dark themes
- English and Arabic language support
- Project galleries organized into **Websites**, **Apps**, and **Games**
- Featured-project slider and project detail popups
- Sections for skills, experience, education, achievements, and contact information

## Tech Stack

- **Frontend:** React, JavaScript, HTML, CSS
- **Routing:** React Router
- **Internationalization:** React Intl (`en.json` and `arb.json`)
- **Project showcase:** Swiper

## Getting Started

### Prerequisites

- Node.js and npm

### Run Locally

```bash
git clone https://github.com/Imaad00/My-portfolio.git
cd My-portfolio
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
